# RACING IBR v0.1 — 西池袋ナイトレーサーズ

現代の西池袋を舞台にした一人用レーシングRPG。夜の街を流す走り屋にパッシングでバトルを挑み、勝って奪ったパーツで愛車「86-GR」を強化していく。
v0.1 はエンカウントバトルシステムの実装版です（ストーリー・ガレージは今後のバージョンで追加）。

## 起動方法

ビルド済みの `dist/game.js` を同梱しているので、`index.html` をブラウザ（Chrome / Edge 推奨）で開けば遊べます。
ローカルサーバー経由でも起動できます：

```bash
npm install
npm run build
npx esbuild --servedir=. --serve=8080   # http://localhost:8080
```

開発時は `npm run dev`（ファイル変更を監視して自動ビルド、http://localhost:8080 で配信）。

## 操作（デフォルト / CommonSettingで変更可）

| 操作 | キー |
|---|---|
| アクセル | F |
| ブレーキ | S |
| パーシャルアクセル / パーシャルブレーキ ※追加 | G / B（一定の開度で踏む。開度はセッティングで車ごとに設定、初期値 50% / 40%） |
| ハンドブレーキ ※追加 | N（後輪だけに強いブレーキ。ABSは効かず後輪をロックできる。引いている間はクラッチを切る＝FR/AWDでもエンストせず向きを変えられる。FFはクラッチを切らない） |
| シフトアップ / ダウン | E / D |
| 左 / 右ハンドル | J / L |
| バックミラー（表示切替） | K |
| 視点切り替え | I（後方 → 運転席 → ボンネット） |
| パッシング ※追加 | H |
| 決定・入店 ※追加 | Enter |
| 車両リセット | R（進行方向前向き・道路中央・0km/hに戻す。バトル中は10km/h以下のときのみ、10m後方へ） |
| ポーズ / 戻る | Esc（固定） |

- デフォルトは **AT（オートマ）・ABS 10・トラクションコントロール 10**。CommonSettingで MT／AT、**スピン防止アシスト（初心者用）のON/OFF**、明るさ、音量を変更可。
- **ABS・トラクションコントロール**（0=OFF〜10の段階）と**パーシャルアクセル／ブレーキの開度**は、ポーズメニューの「セッティング」→「ドライバーアシスト・操作」で車ごとに設定します（バトル中・タイムアタック中は変更不可）。ABSは数値が大きいほど早く・強く介入。トラクションコントロールは段階ごとに許容する空転量を決めてスロットルを自動制御し、1で大きな空転を許し10でほぼ空転なし（`tools/aids_test.mjs` でレベル別の比較）。
- **スピン防止アシスト**：アクセルON＋ハンドル操作中、駆動輪とリアタイヤがグリップの限界（摩擦円のピーク）を超えないよう、また車体がオーバーステアに入らないようアクセル開度を自動で調整し、スピンせずに曲がりながら加速します（`tools/assist_test.mjs`）。作動中はタコメーター上に ASSIST（TCS作動時は TCS）を表示。
- AT時は停止中にブレーキを踏み続けるとリバース。MT時はニュートラルからさらにシフトダウンでリバース。
- リプレイ中：視点 I または 1〜4（1後方 / 2運転席 / 3ボンネット / 4ギャラリー）、Space 一時停止、←→ 5秒送り/戻し、↑↓ 再生速度。

## 画面構成

- **Story**（NewGame / Continue）… 街に繰り出す。Continue は前回GSでセーブした場所から再開
- **Practice** … TimeAttack（街のコースとサーキットは3周、峠は1本。ラップ・セクタータイム・日時・リプレイを記録）／FreeRun（各コース、または「西池袋／東池袋タウン」「榛名山（峠道全線）」を自由走行）／Records（記録一覧とリプレイ再生）。マシンは「ストーリーのマシン」「ノーマル 86-GR」「ノーマル車（全10車種から選択）」「フルカスタム 86-GR（★5パーツ装着）」から選択
- **CommonSetting** … キー配置変更（重複したキーは入れ替え）、操作設定、明るさ（50〜200%）、音量

## Story（エンカウントバトル）

1. 街（西池袋ミニチュアマップ）を流しているライバルの後ろにつき、**H でパッシング**（ミニマップのライバルは、まだ倒していない相手が赤、倒したことのある相手が緑）
2. ライバルが応じるとバトル開始。パッシングした場所に**一番近いコース**を、自車の向きに合わせて**順走／逆走**で走る
3. ライバルはフェアに走ります：前の車には追突しないよう車間を取り、追い抜きは横に間隔を空けられるときだけ（相手がこの先レーシングラインへ寄ることも見越す）。並走中は反対側へ横切らず、幅寄せされたらアクセルを戻して後ろへ下がります。間隔の取り方は性格で違い、多くは標準（約0.8m）、ギリギリまで寄せる攻撃的な走り屋（黒田ゴウ・獅堂ケンジ・榊リュウ・不知火ゼロ、約0.35m）と大きめに避ける慎重な走り屋（柚木ユウリ・三上カナデ・宮城サクラ・雪村ミオ・篠原カエデ、約1.4m）がいます。腕前に応じてミス（ブレーキが遅れてアウトへはらむ、立ち上がりでアクセルを開けすぎて滑る）もしますが、トップクラス（腕前0.955以上：不知火ゼロ・鳳ガイ・天城カナタ）はほぼミスをしません。競り合い中はミスをしません（ぶつけないため）。`node tools/contact_test.mjs` で接触回数・ミスの頻度を確認できます
4. 先にゴールするか、**200m 引き離せば勝利**（引き離されたら敗北）。バトル中のミニマップは自車中心の約300m四方に拡大
5. 勝利すると賞金と、**ライバル車に付いているパーツを1つ選んで奪える**
6. **TUNE SHOP** でパーツ交換・購入・売却・**中古車の購入**（購入した車はガレージへ）、**GS** でセーブ（各エリアに1か所ずつ。西池袋はドン・キホーテ北池袋店／ENEOSセルフ池袋SSの実際の位置）
7. **ガソリン**（ストーリーの街とバトルで減る。Practiceでは減らない）：エンジンが出している出力×燃料消費率（最良約235g/kWh。低負荷・高回転・ターボの過給圧が高いほど悪化、アクセルオフの減速中は燃料カット、停車中はアイドル分）で計算し、走行中は実燃費の**10倍の速さ**で減ります（停車中のアイドリング・空ぶかしは実燃費どおりで、駆動輪に仕事をしていない空ぶかしは摩擦分しか燃料を使いません）。タンク容量は各車の公表値。GSで給油（ハイオク185円/L、満タン／10L。所持金が5L分もないときは5Lまで無料の救済給油）。ガス欠になるとエンジンの力がほとんど出なくなり、**時速30km以下でだけ**自走できます。回転計の上に残量と瞬間燃費を表示。`node tools/fuel_test.mjs` で車種ごとの燃費（実燃費相当：例 86-GR 60km/h定速で約16km/L、全開加速で約2km/L）を確認できます。ATは軽いアクセルの巡航では早めにシフトアップします
8. **タイムランキング**（GSで）：その街の各コースについて、街を走っているライバル全員の完走時の参考タイム（バトルと同じ周回数・単独走行でAIが走ったタイム。`node tools/reftimes.mjs` で再計算 → `src/data/reftimes.js`）と、あなたのベストタイム（バトルで完走したとき記録）を並べ、誰が速いか・あなたが何位かを表示。撃破済み／未遭遇のライバルも分かります
9. **ガレージ**（ポーズメニュー）：所有車の一覧、車を全方位から確認（←→回転・Z/X上下・C/Vズーム・1〜6で前/後/左/右/真上/真下・マウスドラッグ）、シャシー表示（重心・車軸・駆動輪・200km/h時の空力を矢印で表示）、乗り換え、セッティング
10. **サーキット走行会**（ポーズメニュー）：参加費を払って、つくば山麓サーキット（¥25,000）・鈴鹿丘陵サーキット（¥50,000）・富士山麓サーキット（¥45,000）を1枠15分走れます（ストーリーのマシンのチューニング・セッティング・燃料そのまま。走行会では燃料は実燃費どおりに減ります）。グリッド後方からアウトラップでスタートし、コントロールラインを通過した周からタイム計測。残り時間0でチェッカー、その周で終了。ベストラップは走行会の自己ベストとして残ります（ポーズメニューの項目に表示）。走行中もセッティングを変更可。終わると元いた街の場所へ戻ります
11. **サーキットレース**（ポーズメニュー →「サーキットレース（8台出走）」）：筑波・鈴鹿・富士で、プレイヤーを含む8台のレース。詳細は下の「サーキットレース」
12. **エリア移動**：川越街道の東端・メトロポリタン通りの南端にある緑の看板の先まで走るか、ポーズメニューの「エリア切り替え」で西池袋⇔東池袋を移動（暗転して向こうの対応する道路に速度0で出ます）

勝利数（西・東の合計）に応じて強いライバルが街に現れます。西池袋に12人（5車種）、東池袋に10人（新しい5車種）。**10勝で榛名山エリアが解放**され、ポーズメニューの「エリア切り替え」から移動できます（榛名山のライバル8人は★5パーツを組み、各自のセッティングを持っています）。BGM は街＝Midnight Bliss、バトル＝追い抜け駆け抜けろ!的なBGM。

## 挙動モデル（`src/physics/vehicle.js`）

500Hz固定ステップ。Pacejka 型タイヤカーブ＋摩擦楕円によるコンバインドスリップ、エンジントルクカーブ／ターボラグ／レブリミッター、ギア・ファイナル・半クラッチ発進、FF/FR/AWD、ABS・トラクションコントロール（0〜10段階）、空気抵抗・転がり抵抗、壁・車両同士の衝突（インパルス）。キーボード操作向けに速度感応ステアリング（カウンターステア時は追加で切れる）。

- **タイヤの縦グリップと回転慣性**（`node tools/launch_test.mjs` で0-100km/hの内訳＝スリップ率・変速時間・ギア別時間を確認。`TCS=10` で トラクションコントロール10）：タイヤの縦方向（駆動・制動）の摩擦係数は横方向の約1.12倍（摩擦楕円）。エンジンの回転慣性（クランク＋フライホイール＋クラッチ）は実機相当。トラクションコントロール10での0-100km/h：86-GR 6.3秒（実車 6.3秒）、Z-32 5.8秒（5.8秒前後）、S2K-AP 6.2秒、RS-RS 7.7秒。トラクションコントロールOFFで全開（キーボードのON/OFF操作）だと、FR車は1速の駆動力がタイヤのグリップを上回るため1速の間ホイールスピンが続きます（実車でもアクセルとクラッチの調整が必要な領域）。パーシャルアクセル（G）やトラクションコントロールで抑えられます。加速・制動時の前後荷重移動は `node tools/loadtransfer_test.mjs` で理論値（ΔF = m·a·重心高 / ホイールベース）と比較でき、定常状態で±0.5%以内で一致します（例：SWIFT-Sは0.5G加速で前輪荷重 62%→51%、FFなので駆動輪のグリップが減る）。
- **サスペンション**：4輪それぞれのばね（固有振動数から算出）・ダンパー（縮み側／伸び側の減衰比）・スタビライザーと、ばね上の上下・ピッチ・ロールの運動方程式を解いて輪荷重を求めます。荷重移動は「タイヤ力が接地面（重心より下）に働くモーメント」から生じ、ロール・ノーズダイブ・スクワットが物理的に起きます。ストロークが尽きるとバンプラバー→底打ち（抵抗増）。
- **キャンバー・トー**：車体ロールによるキャンバー変化を含めて、横グリップは2〜3°ネガティブで最大、静的キャンバーを付けるほど縦（制動・加速）グリップが低下。トーは各輪の向きとして計算するので、前アウト＝回頭性↑、後イン＝安定↑が自然に出ます。
- **デフ／LSD**：各輪の回転を独立に解き、軸ごとに「平均回転」と「左右差」に分けて陰解法で積分。LSDはイニシャルトルク＋加速感度（アクセルON）／減速感度（アクセルOFF）×入力トルクまで左右差を止めます。純正も車種ごとにトルセン・機械式・ビスカス・オープンを設定。AWDのセンターは直結扱い。
- **車種ごとのシャシー・ボディ**：駆動方式・ホイールベース・前後トレッド・前後重量配分・重心高・車高に加え、**ヨー慣性**（Iz = 質量×前軸距離×後軸距離×動的指数。軽量オープンは小さく回頭が速い、前に重い車は大きい）と、**ボディの前後揚力係数**（高速ほど前後輪の荷重が抜ける量が車ごとに違う。ウイング・エアロのダウンフォースはこれに加算）を車種ごとに設定。AWDは**センターデフ**を車種別に再現：WRX-IMP＝前41:後59＋差動制限、EVO-IX＝50:50＋強めの差動制限、R34-GTR＝基本FRで後輪が空転すると前輪へ最大約50%まで伝える方式（フルカスタマイズミッションで前後配分を変更可）。`node tools/chassis_test.mjs` で車種ごとの差を確認できます。
- **勾配・起伏**：路面の高さを4輪の位置で取り、勾配による前後・横方向の力（垂直抗力の水平成分）、凸（クレスト）での荷重抜け・ジャンプ、凹（サグ）での荷重増をサスペンションを通して計算します。車体は路面の傾き＋サスペンションの姿勢で描画。

| エアロ | フロントリップ / GTウイング（ダウンフォース調整可）/ フルエアロ（前後調整可） |
| ホイール | 純正 / 軽量鍛造（純正サイズ）/ +1インチ / +2インチ / 軽量鍛造+1インチ / 軽量鍛造+2インチ |
| タイヤ幅 | 純正 / +10mm / +20mm / +30mm |

**ホイールとタイヤ幅**（`node tools/wheel_test.mjs` で比較）：外径は純正のまま（インチアップ分は扁平率を下げる）。各車の純正サイズは公表値（例 86-GR 215/40R18）。
- グリップ：タイヤ幅は接地面積に対して頭打ちで増える（幅の0.25乗、荷重感度のため）。インチアップは扁平化でサイドウォールが硬くなり横剛性が上がる（ピークに達するスリップ角が小さく＝応答が鋭い）＋グリップ1.5%/inch程度。
- デメリット：1輪あたりの重量増（+1inch 1.6kg、+2inch 3.4kg、幅10mmごと0.6kg）を車重に、回転慣性の増加（+12%/+26%）を加速・制動に、幅広タイヤの転がり抵抗・前面投影面積の増加を最高速・燃費に反映。軽量鍛造は逆に軽く回転も軽くなる。純正ブレーキのままだと、重く回転慣性の大きいホイールでは制動距離が少し伸びる。
- 見た目：タイヤ幅パーツで3Dモデルの車輪が横に広がる（外側へはみ出す）。純正ホイール・純正幅はいつでも戻せる（売却不可）。

★1〜2は主にショップで購入、★3〜4はライバルから奪うことでしか手に入りません。★5フルカスタマイズパーツは榛名山のライバルから奪うか、榛名山のショップで購入できます。

## サーキットレース（`src/modes/raceweekend.js` / `src/data/races.js`）

- **レギュレーション（クラス分け）**：パワーウェイトレシオ（車両重量kg÷最高出力PS）で **クラスA（3.9kg/PS以下）／B（3.9〜5.0）／C（5.0超）**。今乗っている車のクラスに出走し、同じクラスのライバル7人が参加します（今の勝利数に近い＝街で出会う頃合いのライバルほど選ばれやすく、出走するたびに顔ぶれが少し変わる。クラスに7人いなければPWRの近いライバルで補充）。エントリー画面で出走者・車・PWRを確認できます。
- **参加費・賞金**：クラスとサーキットで変わります（クラスC・筑波で参加費¥50,000、優勝¥400,000〜8位¥50,000。B×1.6、A×2.5、鈴鹿×1.5、富士×1.35）。参加費には満タン給油が含まれます。燃料は実燃費どおりに減ります。
- **プラクティス（15分）・予選（15分）**：時間制。ライバル7台も同時にコースを走り、コントロールラインを通過した周からタイムを計測。どちらも**省略可**（予選を省略すると最後尾スタート）。ポーズメニューで「現在の順位」の確認、セッティング、ホームストレートへ戻る、「終了して次へ進む」ができます。時間を残して終えると、残り時間にライバルが走る分を見積もってタイムに反映するので、**ライバルがタイムを上げて順位が入れ替わることがあります**。残り時間0でチェッカー（走行中の周は計測）。
- **決勝**：予選のベストラップ順のグリッド（2列の千鳥）から**スタンディングスタート**。シグナル5灯が1秒ごとに点灯し、0.3〜1.2秒後に消灯でスタート（消灯まで車は動かせないのでフライングはありません）。周回数は筑波5周・鈴鹿3周・富士3周。順位・前後とのタイム差をHUDに表示。プレイヤーのゴール後、他車のゴールを最大30秒待ち、まだ走っている車はそれまでのペースでゴールタイムを見積もります。リセットは10km/h以下のとき10m後方へ。ポーズメニューからリタイア可（賞金なし）。
- **ライバルの見積もり**：`node tools/reftimes.mjs`（`ONLY=circuit` でサーキットだけ）で全ライバルの単独・ミスなしのフライングラップを計算（`src/data/reftimes.js`）。そこに腕前に応じたばらつき・ミスを加えて1周ずつ見積もります。`node tools/race_test.mjs`（`KEY=suzuka_gp CLS=B` など）でAIだけの8台レースを確認できます。
- AIはグラベル・バリアで約8秒動けなくなるとコースへ戻ります（オフィシャルの救出に相当）。
- 今後：ローリングスタート、タイヤ摩耗と耐久レース。
