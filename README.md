# RACING IBR v0.1 — 西池袋ナイトレーサーズ

現代の西池袋を舞台にした一人用レーシングRPG。夜の街を流す走り屋にパッシングでバトルを挑み、勝って奪ったパーツで愛車「86-GR」を強化していく。
v0.1 はエンカウントバトルシステムの実装版です（ストーリー・ガレージは今後のバージョンで追加）。

## 起動方法

ビルド済みの `dist/game.js` を同梱しているので、`index.html` をブラウザ（Chrome / Edge 推奨）で開けば遊べます。
ローカルサーバー経由でも起動できます：

```bash
npm install
npm run build
npx esbuild --servedir=. --serve=8080   # http://localhost:8080
```

開発時は `npm run dev`（ファイル変更を監視して自動ビルド、http://localhost:8080 で配信）。

## 操作（デフォルト / CommonSettingで変更可）

| 操作 | キー |
|---|---|
| アクセル | F |
| ブレーキ | S |
| シフトアップ / ダウン | E / D |
| 左 / 右ハンドル | J / L |
| バックミラー（表示切替） | K |
| 視点切り替え | I（後方 → 運転席 → ボンネット） |
| パッシング ※追加 | H |
| 決定・入店 ※追加 | Enter |
| 車両リセット | R（進行方向前向き・道路中央・0km/hに戻す。バトル中は10km/h以下のときのみ、10m後方へ） |
| ポーズ / 戻る | Esc（固定） |

- デフォルトは **AT（オートマ）・トラクションコントロールON・ABS ON**。CommonSettingで MT / ABS / トラクションコントロール / 音量を変更可。
- AT時は停止中にブレーキを踏み続けるとリバース。MT時はニュートラルからさらにシフトダウンでリバース。
- リプレイ中：視点 I または 1〜4（1後方 / 2運転席 / 3ボンネット / 4ギャラリー）、Space 一時停止、←→ 5秒送り/戻し、↑↓ 再生速度。

## 画面構成

- **Story**（NewGame / Continue）… 街に繰り出す。Continue は前回GSでセーブした場所から再開
- **Practice** … TimeAttack（3周、ラップ・セクタータイム・日時・リプレイを記録）／FreeRun（各コース、または「西池袋タウン」で全道路を自由走行）／Records（記録一覧とリプレイ再生）
- **CommonSetting** … キー配置変更（重複したキーは入れ替え）、操作設定、明るさ（50〜200%）、音量

## Story（エンカウントバトル）

1. 街（西池袋ミニチュアマップ）を流しているライバルの後ろにつき、**H でパッシング**
2. ライバルが応じるとバトル開始。パッシングした場所に**一番近いコース**を、自車の向きに合わせて**順走／逆走**で走る
3. 先にゴールするか、**200m 引き離せば勝利**（引き離されたら敗北）
4. 勝利すると賞金と、**ライバル車に付いているパーツを1つ選んで奪える**
5. **TUNE SHOP** でパーツ交換・購入・売却、**GS** でセーブ（各エリアに1か所ずつ。西池袋はドン・キホーテ北池袋店／ENEOSセルフ池袋SSの実際の位置）
6. **エリア移動**：川越街道の東端・メトロポリタン通りの南端にある緑の看板の先まで走るか、ポーズメニューの「エリア切り替え」で西池袋⇔東池袋を移動（暗転して向こうの対応する道路に速度0で出ます）

勝利数（西・東の合計）に応じて強いライバルが街に現れます。西池袋に12人（5車種）、東池袋に10人（新しい5車種）。BGM は街＝Midnight Bliss、バトル＝追い抜け駆け抜けろ!的なBGM。

## 挙動モデル（`src/physics/vehicle.js`）

500Hz固定ステップ。4輪それぞれの荷重（前後・左右の荷重移動、空力ダウンフォース）、Pacejka 型タイヤカーブ＋摩擦楕円によるコンバインドスリップ、エンジントルクカーブ／ターボラグ／レブリミッター、ギア・ファイナル・半クラッチ発進、FF/FR/AWD、ABS、空気抵抗・転がり抵抗、壁・車両同士の衝突（インパルス）。キーボード操作向けに速度感応ステアリング（カウンターステア時は追加で切れる）。

## マップとコース（`src/data/map.js`）

添付の Google マップ画像の経由地座標と経路から主要道路の折れ点を緯度経度で起こし、0.7倍に縮小したミニチュアの街として実装（道幅と車は実寸）。範囲は山手通り・川越街道・劇場通り・都道441号に囲まれた西池袋エリア。

| コース | 長さ | 周回 | 経路 |
|---|---|---|---|
| 西池袋スピードウェイ | 約2.98km | 1 | 山手通り → 川越街道 → 劇場通り → 都道441号 |
| 池袋WGP | 約0.63km | 3 | 西口公園周辺〜文化通り〜みずき通りの路地 |
| 立教通りサーキット | 約1.27km | 2 | 立教通り → 名物ヘアピン → 要町通り → 山手通り |
| 東池袋ロングコース ※東 | 約3.10km | 1 | 春日通り → 大塚 → 不忍通り → 首都高下の道 → 東池袋駅 → 春日通り |
| サンシャインサーキット ※東 | 約0.90km | 2 | サンシャイン60通り → 首都高下の道 → グリーン大通り → 東口の明治通り |
| 南池袋ループ ※東 | 約1.72km | 2 | 都電沿いの道 → 首都高下の道 → 東池袋駅 → グリーン大通り → 明治通り |
| 東口ストリートコース ※東 | 約1.56km | 1 | 東池袋一丁目の路地 → サンシャイン60通り → 首都高下の道 → グリーン大通り → 明治通り |
| サンシャインシティ外周 ※東 | 約1.26km | 2 | 東池袋駅 → サンシャインシティ西側 → 北側 → 春日通り → 東側 → 東池袋駅 |

各コース順走／逆走。西池袋3コース・東池袋5コースの計16レイアウト。立教通り東端〜要町通りの鋭角ターンは実寸のまま再現しています。

- **コーナー拡幅**：20°以上曲がるコーナーは、コーナー前後14mでコース幅をイン側・アウト側の両方へ合計3〜5m（急なコーナーほど広く）拡げ、さらに14mかけて元の幅へ戻します。
- **見える障害物**：走行可能範囲の境界（＝当たり判定）に沿って縁石（低い段差）を置き、その外側に街ではガードレールと植え込み、コースでは紅白のガードレールを配置。コーナー付近の縁石は紅白。交差点など走れる場所は切れ目になります。
- ショップ・GSの位置は住所からの近似です。

## 街の再現（西池袋タウン）

レースコースの形状・幅は変えずに、街（Story／FREE RUNタウン）側だけを細かく再現しています。

| 道路 | 車線構成（推定） | 再現要素 |
|---|---|---|
| 山手通り | 片側2車線・中央分離帯2m | 分離帯（当たり判定あり）、交差点手前の右折レーン・矢印、歩道橋 |
| 川越街道 | 片側2車線・中央分離帯3m | 上空に首都高5号池袋線（門型橋脚）、右折レーン |
| 劇場通り | 片側2車線・黄色の中央線 | 曲線をなめらかに補間、歩道橋 |
| 都道441号 | 片側1車線・広い路肩 | 添付画像から曲がりを細かくトレース |
| 立教通り・要町通り ほか | 片側1車線 | 破線の中央線、歩道橋（要町通り） |

- 全交差点に横断歩道・停止線、3方向以上の交差点に横型信号機（青10秒・黄3秒・赤のサイクル）
- **池袋駅西口**：駅ビル「東部デパート」（架空名）、西口出入口の庇、駅前広場の舗装
- **西口ロータリー**：走行可能な八角形のループ（時計回りの一方通行）と、中央の島のバス乗り場
- **西口公園**：円形ステージとLEDで色が変わるリング状の大屋根、植栽、街灯
- **池袋芸術劇場**（架空名）：公園側に傾斜した大ガラス屋根のアトリウム
- **西一番街**：走行可能な路地。入口のアーチ看板、提灯、縦型ネオンの飲食店（店名はすべて架空）
- 街流しのライバルは車線に沿って走り、交差点では道路からはみ出さない曲線で右左折します。同じ向きの前の車には追従し、長く詰まったときは横をすり抜けます（行き止まりには入りません）
- 狭い道の110°以上の鋭い曲がり角は隅切り（角を丸く広げる）にしています（`tools/cruise_test.mjs` で多数台の走行を検証）

## 東池袋エリア

添付の「東池袋エリア」「東池袋ロングコース」画像から道路を起こしています（道路名・車線構成は推定）。

| 道路 | 車線構成（推定） |
|---|---|
| 春日通り（国道254号） | 片側2車線・分離帯1.5m。西端が池袋大橋（西池袋の川越街道へ） |
| 明治通り（池袋駅東口） | 片側2車線。南端がメトロポリタン通り方面（西池袋へ） |
| 首都高下の道（都道435号） | 片側2車線・分離帯3m。上空に首都高5号池袋線 |
| グリーン大通り | 片側2車線・並木の分離帯4m（東口〜東池袋駅） |
| 不忍通り／大塚の通り／サンシャイン60通り／都電沿いの道 | 片側1〜2車線 |

- **池袋駅東口**：線路沿いの駅ビル「西部デパート」、北側の「パルクス」、明治通りの向かいの家電量販店とアニメーションする大型ビジョン（名称はすべて架空）

- **サンライズシティ**（サンシャインシティ風・架空名）：高さ約240m相当の主タワー（西池袋からも遠景で見える）、ホテル棟、中層棟と屋上の水族館ドーム、低層の商業棟
- **東池袋駅**：地下鉄の出入口
- 施設：チューニングショップ（大塚の通り沿い）、GS（春日通り沿い）。位置は架空です
